# Marca de ParlAR

**Caret de voz**: barras de voz que crecen hacia el cursor de escritura
(ladrillo). La voz llega al punto de inserción.

| Archivo | Uso |
|---|---|
| `../parlar.svg` | App icon (launcher, `.desktop`, ventanas, portfolio) |
| `parlar-16.svg` | Máster de 16 px: favicon, menús, ícono de ventana chico |
| `parlar-mono.svg` | Símbolo de un color (`currentColor`): web, sellos, fondos claros |
| `../tray/parlar-tray*.svg` | Tray: normal, activo (grabando), atención |

Sistema compartido con GuionAR: rejilla 64 con módulo 4, baldosa 56×56 en
(4,4) con radio 14, barras de 6 u con extremos redondos, un solo acento.
ParlAR usa barras **verticales** (voz); GuionAR, **horizontales** (lectura).
Colores: baldosa `#1E1F22`, barras `#7E7C79` → `#E9E6E1`, cursor `#C0603F`.
