# ParlAR 1.1.0

ParlAR ahora se instala desde una release descargable, sin clonar el
repositorio ni compilar, y suma una ventana de Configuración, ícono en la
bandeja e integración automática con GuionAR.

## Novedades

- **Configuración en una ventana**: dictado, micrófono (con prueba de
  nivel), atajo, GuionAR, inicio con la sesión y opciones avanzadas.
- **Ícono en la bandeja** con el estado, pausa, Configuración, reinicio y
  salida, y entrada en el menú de aplicaciones.
- **GuionAR automático**: si el teleprompter está abierto, ParlAR se conecta
  solo, le envía lo que vas diciendo en vivo y, por defecto, el dictado va
  sólo a GuionAR mientras está conectado.
- **Nuevo atajo predeterminado** (Ctrl derecho + Super derecha) para
  instalaciones nuevas. Si ya tenías un atajo, se conserva.
- **Reinicio seguro** que no corta un dictado en curso.
- **Instalación desde la release**, actualización que no rompe la versión
  vigente si algo falla, `parlar-uninstall` y `parlar --version`.

La lista completa está en [CHANGELOG.md](../CHANGELOG.md).

## Instalar

Descargá `parlar-1.1.0-linux-x86_64.tar.gz` y `SHA256SUMS`, y en esa carpeta:

```bash
sha256sum -c --ignore-missing SHA256SUMS
tar -xzf parlar-1.1.0-linux-x86_64.tar.gz
cd parlar-1.1.0
./install.sh --preload-model
```

Después abrí ParlAR desde el menú de aplicaciones. Los paquetes del sistema
necesarios están en el [README](../README.md#instalar).

**Requisitos:** Linux x86_64 con glibc 2.28 o posterior y Python 3.12, 3.13
o 3.14 con `venv`. No hace falta compilador. Con otra versión de Python, el
instalador se detiene antes de cambiar nada y lo indica.

## Si tenías ParlAR 1.0.x

Ejecutá el `./install.sh` de esta release. Reconoce la instalación anterior,
instala 1.1.0 al lado, la valida y recién entonces la activa. Tu
configuración, tu atajo y tus transcripciones quedan como estaban. Después,
**Salir** desde la bandeja y volvé a abrir ParlAR desde el menú. La copia del
repositorio que usabas para instalar ya no hace falta.

## Desinstalar

```bash
parlar-uninstall                # conserva configuración y transcripciones
parlar-uninstall --purge-data   # las borra también
```

El modelo de voz descargado queda en `~/.cache/huggingface`, que otras
aplicaciones pueden compartir; el README explica cómo borrar sólo el de
ParlAR.

## Limitaciones conocidas

- Validado a mano en Fedora con X11. En Wayland funciona con un atajo
  asignado desde el escritorio y no fue validado a mano.
- `Esc` cancela el dictado pero también puede llegar a la aplicación con
  foco.
